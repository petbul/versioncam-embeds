This page cannot hold the iframe snippet as version.cam gave it on 2026-11-10. With it, `docusaurus build` fails for the whole site:

```text
Error: The `style` prop expects a mapping from style properties to values, not a string.
```

The snippet was:

```html
<iframe src="https://clips.version.cam/versioncam/versioncam/01-create-a-shipment/embed" style="width:100%;aspect-ratio:1280/800;border:0" allow="fullscreen" loading="lazy" title="Create a shipment"></iframe>
```

The next page has the same iframe as JSX, which builds and plays.
